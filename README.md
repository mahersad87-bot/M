# معاون الذكي

تطبيق ويب يعمل بالكامل داخل المتصفح (ملف HTML واحد، بدون خادم) لإدارة سجلات المدرسة: الطلبة، الغياب، الجداول، والمخاطبات الرسمية.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | التطبيق كاملاً |
| `manifest.webmanifest` | إعدادات التثبيت كتطبيق (PWA) |
| `icon-192.png`, `icon-512.png` | أيقونات التطبيق |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات عبر Jekyll |

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages

1. ارفع الملفات إلى مستودع جديد على GitHub.
2. من **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة تقريباً يصبح الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظات

- تُحفظ البيانات في المتصفح (`localStorage`) على جهاز المستخدم فقط، ولا تُرفع إلى GitHub.
- يحتاج التطبيق إلى اتصال بالإنترنت عند أول تشغيل لتحميل الخطوط ومكتبات القراءة (PDF / Word / Excel) من CDN.
- لا ترفع إلى المستودع أي ملفات تحتوي بيانات طلبة حقيقية.
